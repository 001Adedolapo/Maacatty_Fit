# Maacatty Fits | Bespoke Excellence
**Premium Tailoring Services. Crafted in Enugu.**

Maacatty Fits is a high-fidelity web platform designed to disrupt traditional agency practices by providing a "trust-based" digital experience for bespoke tailoring.

## 🚀 Live Demo
[View the Live Site](https://ebenezer-dev.github.io/maacatty-fits/) *(Replace with your actual link)*

## ✨ Key Features
* **The Lookbook:** A curated gallery of signature styles and high-fashion designs.
* **The Vault:** A secure digital archive where clients store precise anatomical measurements for life.
* **Direct-to-WhatsApp Integration:** Seamlessly bridges the gap between digital selection and personal consultation.
* **Responsive UI:** Optimized for premium mobile and desktop experiences.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Grid & Flexbox layouts)
* **Design:** Figma (High-fidelity prototyping)
* **Icons:** Lucide-icons
* **Typography:** Play zfair Display & Inter (Google Fonts)

## 📂 Project Structure
* `index.html` - Homepage and brand story.
* `lookbook.html` - Product showcase.
* `vault.html` - Measurement submission portal.
* `craft.html` - The 4-step bespoke process.
* `style.css` - Global brand styles.
